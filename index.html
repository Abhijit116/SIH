Our Solution

An offline, multilingual and lightweight Android communication system that transforms spoken messages into lightweight text (STT), transmits them with minimal data over local Wi‑Fi/Bluetooth connections, and reconstructs them as clear speech on the receiving device using TTS.

Speech
STT → Text
Wi‑Fi / Bluetooth
TTS → Speech
Multiple‑Device Broadcasting

Broadcast emergency alerts to all nearby iTantra devices simultaneously.

Emergency Location Radar

Displays direction, distance, and location of emergency devices using GPS.

Background SOS Alert

Receive high‑priority SOS alerts without requiring the app to be actively open.

Translated Message

Translate received messages into the user’s preferred language.

Multilingual Support

Offline STT/TTS support for 10 Indian languages + English.

Multi‑Device Support

Connect with multiple devices simultaneously and talk with any selected device.
